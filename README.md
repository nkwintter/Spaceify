# 🚀 Spaceify - Sua Playlist Intergaláctica

O Spaceify é uma aplicação mobile inovadora que combina a vastidão do cosmos com sua paixão por música. Utilizando imagens espaciais da NASA, o app gera playlists personalizadas baseadas no mood e emoções que cada imagem celestial desperta.

# Equipe

Aline Mielli, Dandara Lima, Letícia Teles, Nathan Gomes, Nikolas Wintter e Thais Costa.

## 🛠️ Tecnologias Utilizadas

React Native - Framework para desenvolvimento mobile

Expo - Plataforma de desenvolvimento

TypeScript - Tipagem estática

Context API - Gerenciamento de estado global

AsyncStorage - Armazenamento local

NASA API - Imagens espaciais

Spotify Web API - Integração com playlists
## 🌟 Funcionalidades Principais

🖼️ Galeria Espacial

Imagem do Dia da NASA: Descubra diariamente uma nova perspectiva do cosmos
Categorias Temáticas: Explore nebulosas, estrelas, planetas e galáxias
Navegação Intuitiva: Interface fluida para explorar o universo

🎵 Geração Inteligente de Playlists

Mood Detection: Algoritmo que analisa as características visuais das imagens

💾 Persistência de Dados

AsyncStorage: Salve suas Imagens e Playlist favoritas localmente

🧭 Navegação Avançada

Tab Navigation: Acesso rápido às seções principais

🎭 Context Global

Theme: Suporte a temas claro/escuro
